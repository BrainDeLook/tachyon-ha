# Tachyon Home Assistant add-on

Tachyon — быстрый self-hosted web-клиент для IMAP/SMTP, контактов и календарей.

## Настройки

- `debug` — подробный вывод запуска (по умолчанию `false`).
- `upload_max_size` — максимальный размер вложения PHP/nginx (по умолчанию `25M`).
- `memory_limit` — лимит памяти PHP (по умолчанию `128M`).
- `secure_cookies` — флаг secure для cookie (по умолчанию `false` для локального HTTP через Home Assistant Ingress).
- `preconfigure_gmail` — добавить и включить Gmail как домен с IMAPS `imap.gmail.com:993` и SMTPS `smtp.gmail.com:465` (по умолчанию `true`). Существующий домен с ручными настройками не перезаписывается.
- `gmail_cache_enabled` — включить фоновую загрузку 50 последних писем из Gmail «Входящие» (по умолчанию выключено).
- `gmail_cache_email` и `gmail_cache_password` — полный адрес Gmail и пароль приложения для фоновой загрузки. Пароль вводится только в настройках аддона, не в чате.

Фоновая загрузка обновляет локальную копию каждые 5 минут. Текст последних 50 писем открывается из `/data/tachyon/ha-message-cache` при уже открытой сессии, даже если в этот момент Gmail недоступен; вход в Tachyon, список писем, вложения, более старые письма и другие папки по-прежнему требуют IMAP. Это не полноценный офлайн-режим. После включения первая загрузка может занять время. Папка кэша переживает перезапуск аддона, но не входит в резервную копию (её можно скачать заново). Доступ к паролю приложения получает фоновый процесс аддона; учитывайте это при выдаче доступа к настройкам и резервным копиям HA.

После установки в форме входа достаточно указать полный Gmail-адрес и пароль приложения. Обычный пароль Google для IMAP/SMTP обычно не принимается; если пункт «Пароли приложений» недоступен, нужен OAuth или политика администратора Google Workspace.

Кнопка «Открыть веб-интерфейс» и пункт Tachyon в боковой панели используют Home Assistant Ingress. При открытии в Home Assistant Tachyon запрашивает полноэкранный режим; кнопка «Home Assistant» в левом нижнем углу открывает боковую панель HA. Вне Ingress полноэкранный режим не включается. Аддон получает динамический префикс Ingress и разрешает встраивание интерфейса только в страницу того же сайта.

Данные Tachyon находятся в постоянном каталоге аддона `/data/tachyon`. Пароль панели администратора находится в `/data/tachyon/_data_/_default_/admin_password.txt` после первого запуска. Версия 4.2.24 один раз переносит подходящие данные из прежнего Docker-тома, если он доступен.

Web-интерфейс слушает внутренний порт `8888`; прямой сетевой порт наружу не опубликован.
