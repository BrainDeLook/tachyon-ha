# Tachyon для Home Assistant

Home Assistant add-on для [Tachyon](https://github.com/kimusan/Tachyon) — self-hosted web-клиента электронной почты, контактов и календарей.

## Установка

1. В Home Assistant откройте **Настройки → Дополнения → Магазин дополнений**.
2. Откройте меню `⋮` → **Репозитории**.
3. Добавьте URL этого репозитория.
4. Установите **Tachyon** и запустите его.

После запуска откройте Web UI аддона через Ingress. Для первого входа в панель администратора используйте ссылку `/?admin`; пароль создаётся при первом запуске и находится в файле `admin_password.txt` внутри каталога данных аддона.

## Данные и обновления

Данные Tachyon сохраняются в штатном persistent volume `/var/lib/tachyon` из официального образа и переживают перезапуск и обновление аддона. Настройки Home Assistant передаются через `/data/options.json`.
